Fake News Detection is a Streamlit-based machine learning application that classifies news articles as either real or fake using text processing and predictive models. The project applies NLP techniques, including TF-IDF vectorization, and compares multiple classifiers to identify the most effective model for detecting misinformation. Users can enter a news headline or article text and receive a prediction instantly.

This project was developed to demonstrate how machine learning can be used in real-world problem-solving, especially for combating misinformation in digital media.
